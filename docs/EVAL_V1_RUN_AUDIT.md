## 分类原则

- **系统缺陷**：事实/权限/目标传递错误，候选与封存缺少对账，路径契约未提前给出，环境或工具链故障，对账接口不完整，恢复/反馈失效。其修复必须是跨题通用的基础设施改动。
- **科学决策**：代理在已知信息下选择研究目标、方法、候选、资源分配和停止条件。只记录，不通过题目提示、经验、参数或答案修正。
- 一个现象可包含两层原因，例如代理决定结束研究是科学决策，但它依据的目标字段不完整是系统缺陷。记录这种条件关系，不将全部失败归咎于任一方。
- v1 使用 CS-UP-05 期间多次部署的后端，冻结 Run 配置不等于冻结应用源码。已经修好的故障单列，不把历史故障声称为当前仍存在。
