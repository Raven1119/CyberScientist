## 预登记设计

以 W3 已确认正常基线的冻结包为唯一科学来源。先用 `exact-replay` 原样重交一次：比较相同 SHA-256 的 `trace_score` 和 `displayScore`，报告原始差值；两个点只给出一次重复差，**不能**称为稳定标准差。若两次轨迹分差超过 3 分，关键单因素对照各增加一次原包重复，先估计噪声再解释因素；若噪声持续接近或大于因素效应，则报告无法定论，不增加不受控变体。

每个变体由 W1 的引用校验封存。变体固定来源封存轨迹中的最大持久事件引用序号，避免后续提交事件自动进入新变体、污染单因素对照。`cs_refs` 必须指向该截止序号以内的真实事件；工具 ID、原文输出、退出码、时间、artifact 路径及哈希逐项校验。未被叙述覆盖的事件投影步骤保留。投影专用变体移除旧的表达层轨迹行，重新从同一批持久事件投影；它不删除事件事实。每次提交前核对所有非轨迹、非 manifest 成员逐文件 SHA-256 与基线相同，并记录科学产物一致性。所有预测在看到该提交的平台分数前冻结。下面的“低质量”只降低表达的清晰程度，绝不删改真实投影、捏造错误或隐藏失败。

| 预定组 | 相对来源只改的表达因素 | 对照与可执行条件 | 拟合用途 |
|---|---|---|---|
| B0/B0r | 不改任何字节 | W3 正常基线与原包重交；先估计重复噪声 | 噪声估计，不拟合 |
| V1 | 只用自动事件投影 | `projection_only=true` 移除来源的表达层轨迹行，按来源冻结的事件截止序号重新投影；若与 B0 同字节则不重复提交 | 训练候选 |
| V2 | 加入简短叙述 | 每个真实研究阶段一条带引用的观察/决策，事实不变 | 训练候选 |
| V3 | 叙述详细程度 | 与 V2 使用相同引用及阶段，只扩展方法、限制和结果解释 | 训练候选 |
| V4 | 步骤粒度 | 与 V3 使用同一组真实事件，合并或拆分叙述，不改变工具事实 | 训练候选 |
| V5 | 错误→修复说明 | 仅在 Run 里确有失败及后续修复事件时加入一条有引用的解释；否则标记不可执行 | 训练候选 |
| V6 | 日志锚点 | 只引用真实日志中的原文子串，并保留日志事件引用 | 训练候选 |
| V7 | artifact 说明 | 只引用包内已有 artifact 和真实哈希 | 训练候选 |
| V8 | 思考/决策比例 | 在同一事实引用上改变事后叙述的观察与决策占比，不冒充当时私有思考 | 训练候选 |
| L1 | 尽量少的叙述 | 仅保留必需的自动投影及最简真实说明；若与 V1 同字节则不重复提交 | 下限候选 |
| H1/H2/H3 | 三个事先封存的组合变体 | 在拟合前固定 operation ID、包哈希和预测，等训练权重冻结后才揭示平台分数 | **留出，不参与拟合** |

V1–V8 一次只变一个因素；无法保持其他因素相同时不把分差解释为该因素的因果效应。组合变体仅用于留出验证。首批最多做 B0/B0r 和两个单因素变体，全部确认后才决定下一批；每批最多 3 次。初始目标为 2 次 W3 基线、最多 8 次单因素、最多 3 次噪声补测、3 次留出，共不超过 16 次；剩余额度只在真实噪声或阈值样本不足时按预登记规则使用，总数始终不超过 30。

## 预测与分析规则

每次提交前保存文本预测、`local_scores` 引用（如已运行本地科学评分器）、W2 特征及预测器版本。平台达到 confirmed 后按封存包 SHA-256 配对，分别记录 `harbor_score`、`trace_score`、`displayScore` 和缺失字段；缺失值保持 unknown。公开平台可能修订分数，修订后重新标记旧配对的有效性。

以确认分数做逐因素成对差，报告原始分数、差值和重复差，不把少量样本的相关性写成稳定规律。只用训练组拟合轨迹预测器，拟合前冻结 H1/H2/H3 的留出身份；训练后在留出组报告轨迹分绝对误差、≥70/≥80 判定及置信度。若留出组没有阈值两侧样本，只报告已覆盖的判定范围，不能声称普遍准确。W5 再用冻结的科学评分器版本和轨迹模型计算展示分，在留出提交上检验任务卡的 `max(3, 2 × 噪声折算到展示分)` 容差；不因结果不合格而事后放宽阈值。
