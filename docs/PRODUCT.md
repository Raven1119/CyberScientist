# 产品与范围

## 产品定义

CyberScientist 是面向一个操作者的科学竞赛工作台。用户在前端选择题目并给出有界授权后，大脑管理研究方向、平台状态与经验，Prime 自主完成一轮尝试，确定性后端管理进程、远程任务、提交和证据。

### 首版支持边界

| 首版必须有 | 首版不做 |
|---|---|
| Codex、Kimi 两种可切换大脑适配器，逐个交付 | 双大脑同时投票、委员会或自动选模 |
| 一个活跃 Run；Prime 内部子代理默认关闭或受显式额度约束 | 多题并发、多个顶层执行器、分布式调度 |
| Playground 题目导入、契约快照、Attempt 上传与结果核对 | 抓取整站、自动报名、修改官方评分器 |
| bohr 远程计算；本地代码、文件和证据管理 | 本地偷偷运行科学计算作为远程失败的回退 |
| 三个前端入口、真实事件、经验编辑与版本 | 工作流画布、知识图谱可视化、SaaS 多租户 |
| 可查看预算使用和待确认费用，阻止新增超额操作 | 对供应商延迟账单作绝对硬封顶承诺 |

## 用户流程

### 接入

在“连接与设置”分别检测大脑 CLI、Prime、Playground、Bohrium。检测分为“本地安装/配置检查”“只读连接检查”“实际模型工具往返测试”；最后一项明确说明会消耗模型额度，需要用户点击授权。配置完整与连接已验证必须分开显示。

Codex/Kimi 可使用用户已登录的原生运行时，或该运行时实际支持的自定义供应商配置。Prime 使用独立的模型 Profile。Playground 和 Bohrium 算力凭证不能混为一个 API Key。

### 研究

用户粘贴题目 URL 或 ID。系统保存题面、数据引用、提交要求、评分规则及抓取时间，区分比赛与练习。规则不可核实时显示具体缺项，允许只读探索，不自动正式提交。

开始前显示本轮模型配置、经验快照、允许的远程资源与预算、最大提交次数。用户可以一次授权该 Run 的范围内操作，无需确认每个无风险文件读取。

大脑给出当前目标、可证伪假设、下一步区分性实验；Prime 自主选择方法与写代码。科学执行通过 bohr 远程 Job 完成；模型读取已经生成的报告、图表和结构化结果进行判断。

### 结果

工作台显示代码/输入/环境、远程 Job、实验结果、官方反馈之间的对应关系。评分服务异常与科学结果不佳单独标记。大脑决定继续、换方向、准备提交或结束，留下题目内经验；全局经验由明确晋升流程处理。

## 赢的指标

**主指标：相同 challenge 与评分契约下，给定总预算产生的最高有效官方得分。**

记录有效提交率、从启动到有效评分的时间、LLM 用量、远程资源用量、基础设施失败消耗。金额缺报价时显示未知，不显示 0。没有终态分数时不得计算“最高分”。跨题目或评分器版本不直接相加平均，不把练习/赛后分数合并进比赛成绩。

大脑监督和经验带来的收益分别做等预算对照，具体方法见 BUILD。排行榜位置可能变化，只显示来源与更新时间，不将其当作模型能力的唯一证明。

## 模式

| 模式 | 外部写入 | 数据隔离 |
|---|---|---|
| Demo | 无，使用显式测试适配器 | 独立 demo 数据目录；全程标签 |
| Connected/read-only | 可读取已授权资源；模型测试另行授权 | 真实数据目录，未授权操作不可用 |
| Authorized run | 限单个 Run 的模型、资源、有效期和提交额度 | 授权记录随 Run 留存 |

自动运行不是无限权限。用户关闭页面后已授权 Run 可继续；关闭后端则进入恢复流程。
