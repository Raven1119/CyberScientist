# TBMA 运行后升级（2026-09-23）

依据 TBMA 运行的原始审计记录（本机私有保存）中的故障，升级控制入口、证据投影和原生经验整理。历史 TBMA 仍停止；本次不恢复科研、不创建付费 Job、不提交 Attempt。科学结果和旧审计对象保持原件。

## 已实现的闭环

| 本次暴露的问题 | 改动与可用入口 |
|---|---|
| Job 总数/并发只靠提示；超时易重建 | `compute_jobs` 持久账本；`research_job` MCP 和 Run 专用 `bohr` 均走后端。SQLite 事务先占位再创建，operation_id + 输入摘要去重。unknown 占用总量和并发，且阻止继续创建，先查询对账。 |
| 退出码 0 仍可能报错，终止回执不代表停止 | 捕获并脱敏 CLI 双流，识别已观测的文本错误；终止使用已核实的位置参数。stop_unknown 持续保留，只有远端终态释放并发；不会自动重发终止。 |
| 科研进程持有算力账号密钥 | 账号 key 仅注入后端原生 bohr 子进程；Kimi/Prime/Codex 执行器持有 Run 能力令牌。Kimi 原先忽略 spec.env 的问题已修正，大脑也使用环境白名单。 |
| 大脑只看到命令标题，引用过期阶段 | 观测保留工具 ID、状态、退出码和有界结果摘录；Kimi 工具结果补齐标识。帧中的 Job 状态按事件截止序号重建；Job 状态变化会使旧帧指导失效。纯 usage、心跳和 bohr job list 轮询不再触发周期审阅。 |
| 无 Run 的整理输出被 Decision 契约拒绝 | 单独的 CurationResult 协议，不要求 run_id/state_version/actions。全局整理与指定 Run 整理分开。 |
| 原生整理没有读取本轮经历 | `POST /runs/{id}/curation` 冻结本轮公开重要事件、检查点及经验素材，保留外部指导、失败、unknown。提议必须引用快照内真实存在的证据；返回实际保存数量。全局保持 candidate，推导保持 hypothesis。 |
| 开局被“全部资料确认/满分可达”卡住 | 启动提示要求标出已知与缺项，允许推进不依赖缺项的有界 Trial。未实现的 refresh_platform 不再宣传，旧动作明确拒绝。 |
| 小分子探针通过后真实体系资源失败 | 执行器提示明确要求实际规模的最小工作单元试算、资源测量、有限步骤和退出条件；主程序结束同时退出监控。该项是行为要求，仍需下一次真实运行检验。 |

研究页增加「远程任务与本轮经验」：显示账本与 unknown、核对远端、逐任务停止、暂停/结束后的本轮经验整理。浏览器轮询只读本地账本；后端每 45 秒尝试远端对账，不依赖页面保持打开。

## 准入与恢复

- 授权保存 `job_limits_json`，当前前端明确展示：同时 2 个、每个最多 16 CPU / 16 GB 内存 / 10 GB 磁盘，无 GPU。API 可设置正整数上限；不接受 GPU。累计失败任务仍计入 max_jobs。
- Job 必须单节点、关闭平台自动重调度，提供有限 max_run_time（分钟），不超过准入时本轮剩余时长。暂停或研究门禁关闭后不能创建。
- 输入只允许当前 Trial/题目目录，无符号链接；冻结文件、SHA256 清单和实际配置保存在 `.cyberscientist/job-inputs/<operation_id>/`。拒绝常见凭据文件与已知算力 key；不更改源研究文件。
- 重启把 submitting/stopping 转成 unknown/stop_unknown 并留事件，随后仅查询；没有已核实的远端状态就不释放占位。终态不会被迟到回执降回运行。
- 升级前 Run 没有完整账本，不能把空表当作剩余全部额度；旧 Run 拒绝新增受控计算。其恢复/经验整理/历史读取仍可用。需要计算时先核清旧任务，再创建并授权新 Run。
- Run 整理请求持久化并支持操作 ID 去重；重启中断标 failed，不自动重复模型调用。

## 验证与边界

验证结果与部署回读见 STATUS.md 本日条目。所有新增计算与模型测试使用临时工作区、合成 CLI 回执或假原生运行时；不等同于 Bohrium 真实计费验证。

账本查询使用已验证的 bohr 1.1.0 `job list -n 100 --json` 结构、唯一 Job 名称和已知 ID。列表缺项或解析失败保留 unknown；当前没有跨页查询或人工解除 unknown 的入口。账本尚不包含升级前原生 CLI 任务。

环境白名单和后端代理降低密钥传播，但同一 Linux 用户下的代理并非 OS 安全隔离：全局凭据文件、主动绕开代理的原生程序不是本次硬门禁覆盖面。旧会话中已出现的密钥副本没有清除或轮换。模型总费用仍未知。

真实体系试算、心跳与监控退出要求尚不是通用自动空转判定器；不会凭单次低 CPU 或日志静默自动杀死科学计算。Job 的平台时限、用户主动停止和远端终态分开报告。

## 审计与回退

修改前源文件备份：`.package-checks/upgrade-<timestamp>/source-before.tar.gz` 与哈希清单。数据库迁移仅新增账本/整理表和授权列；保留已有经验修订、Run、Trial、Attempt 及历史事件。旧版本不认识新账本，存在非终态受控 Job 时不可直接回退成无门禁版本；先对账并停止，再在停服和备份状态下处理。
