这是单题公开规则的可执行复刻，历史验证仍属于同一研究路径的回放，标签在开发前已知。规则固定，留一标签不会改变任何参数；不能把这种一致率解释为独立盲测。

历史样本覆盖 0 和 100 两端；70、90、96 的中间分目前只有本地反例支持，没有对应的平台反例回执。完整隐藏 verifier 的资源限制、恶意 Lean 元编程防护和所有异常输入行为仍未证明等价。该评分器不预测轨迹分、最终展示分或比赛有效性。
