## 使用与限制

独立执行 `python -m checks.s4_analysis.judge_replica --bundle ZIP --trace JSONL --task TXT --out JSON`；也可用已冻结的 `--packet`。默认使用单独记录的 MAE 选择及训练映射，`--baseline` 保留原始 v6 合成。输出含预测分、conditional/strict 判定、双裁判缺失证据与配置/输入 SHA。封顶和 hard block 在映射后仍有效。`--correct-selection` 只生成选择纠正记录，不调用模型。

公开 API 非空轨迹常缺工具正文/命令；归档可提供更丰富证据，但不能等同 worker 的实际评分输入。机械封顶、缺失 worker 回执和输入遮蔽会显著限制预测。历史参数不因修复代码而重跑覆盖：新输入先暂存，哈希不一致时拒绝，冻结 packet 原字节保留。没有用模型输出作为科学正确性或提交有效性的证明。
