# 监控故障处理表（供设计助手审阅）

依据 10-07 运维可靠性记录、10-08 旧题账本和本轮真实验证。时限从首次观察起计；超过时限只上报事实和下一步，不无限重复同一检查。指导经 PI 持久队列进入；执行者轨迹不直接接收开发监控消息。后端门禁和授权仍是最终边界。

| 故障 | 默认动作 | 时限 | 超时上报与继续方式 |
|---|---|---|---|
| 沙箱创建超时、TLS失败 | 根据稳定操作ID只读对账，unknown保留容量；显式失败按PI已选同镜像转Job | 10分钟首次上报；镜像准备后端上限45分钟；失败确认后2分钟给回退事实 | 报操作ID、状态、最后观察时间；等待期间继续其他题，PI可准备同镜像Job，不重发unknown创建 |
| Job失败 | 读取当前Job日志和已回传产物，返回第一条错误；下一Job须重新通过强制预检 | 5分钟完成一次归因 | 无法取日志记unknown并报缺失；PI选择修正脚本或换环境，不循环提交原输入 |
| 模型限流/额度不足 | 尊重供应商Retry-After和持久重试预算；新science-first流程不自动切DeepSeek | 10分钟或更早授权到期 | 报实际模型、错误与等待；保留上下文，PI/监控显式选可用档位后继续 |
| 提交unknown | 冻结发送包哈希、账号、原生证据，只读对账；不自动重放 | 2分钟内首次对账，10分钟仍未知上报 | 保留unknown预约；研究可继续形成新完整版本，不能把重发当原提交成功 |
| 不规范回执 | 保存私有原文哈希，按known字段解析，科学/轨迹/最终性分别unknown | 5分钟一次定向检查 | 报缺字段及来源；继续研究，显示分不能充当科学分 |
| 评分超过2小时 | 一次只读查平台状态，确认题目/账号/Attempt绑定 | 2小时提醒，2小时10分钟上报 | 标记评分延迟，不重新提交旧包；继续其他题或完整新版本 |
| 原生协议帧错误 | 中断本次未确认控制动作、保留会话和unknown关闭状态；不重写代理内核 | 2分钟诊断，5分钟上报 | 报CLI版本、帧种类、会话ID及是否发起未知；确认关闭前不创建重叠会话 |
| Run停滞 | 先看digest，再看当前阶段、门禁、活跃Job/沙箱/模型调用 | 静默达到设置的stall_seconds后观察；5分钟给判断 | 区分计算中/等审批/限流/未知；向PI发有界指导，不能把静默当无进展强停 |
| 执行者口头数值与日志不符 | 固定对应文件哈希与行号，经PI要求核实；平台分和日志优先 | 5分钟定位，10分钟上报 | 保留冲突，数值unknown；不改原始日志、不代造新结果或把口头值填进产物 |
| 重部署失败 | 停在失败阶段，确认唯一后端身份和safe-shutdown；保留发布日志 | 健康等待180秒；5分钟决定回退 | 使用已验证较早版本回退一次；失败再报当前可用性，不反复启多个后端 |

这些时限是有界运维默认值，不是供应商完成时间承诺；实际余量/授权更短时，以更短者为准。沙箱续期原生协议尚未确认，不能通过延长本地expires_at伪造续期；到期转同镜像Job并上报。
