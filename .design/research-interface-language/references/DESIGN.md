# 视觉规则

## 基准优先级

本次用户明确要求 > 目标项目业务与可用性 > 包内 V9 冷石墨 HTML 的视觉／动效 > 本规范的默认数值。正文任务优先，装饰不能改变信息含义。

参考截图和 HTML 是具体证据；游戏名只是灵感索引。用户已否定 V7/V8 的弱化动效和墨绿色夜间主色，不应重新采用。

## 气质

**仍由人维护的研究机构。**

尼尔式的克制通过纸面、平面反白、中文衬线标题与规整刻度表达；莱茵生命式秩序通过清楚的信息等级、仪器边框、真实档案编号表达；雨世界的运动影响放在观测对象和交互，保留清晰可见的运动特征。

这些是本项目的设计转译，不是三部作品的官方风格定义。不使用原作 Logo、角色、纹章、截图作为商业界面资产。

## 颜色

`assets/tokens.css` 定义 `--ril-*`，`[data-theme="paper"]` / `[data-theme="night"]` 切换。

| 语义 | 纸面 | 冷石墨夜间 |
|---|---|---|
| bg | #e6e3d7 | #17191A |
| paper | #f5f1e6 | #202223 |
| panel | #dcded0 | #1D2021 |
| ink | #303a31 | #D8D4C7 |
| sub | #64705e | #9D9A90 |
| rule | #bec3ad | #353938 |
| accent | #a34d30 | #C9BDA4 |
| window | #15251e | #111314 |

`muted` 只给非必要刻度和装饰标记；重要正文、按钮名称和错误文本用 `ink` / `sub`。不能为了压低噪声把操作文字做成难以辨认的浅灰。

**夜间主界面禁止改回墨绿。** V9 的 shader 仍有应用内部固定色盘，最近一次色调补丁只改了界面 CSS 变量；本包未偷偷重调 shader。后续需要 shader 变色时，显式改其 palette/uniform，并复核两种主题，不要以全层透明度来假装换色。

## 字体与信息层级

保留本机字体回退，不分发字体文件。UI 用系统无衬线；页面标题优先中文衬线；编号、日志时间和英文字段用等宽。

参考值：页面标题 31px / 1.55，主要问题 21px，编辑正文 16px / 1.95，可切换 18px；普通 UI 14px / 1.7，辅助说明 12px。9px micro 标签只能用于装饰性编号，不能承担唯一信息。

正文不全大写、不拉大中文字距，不给每个标题旁边塞无意义英文。标题可有分字进场；已有正文、光标位置和行宽必须稳定。

## 结构

使用方正面板、1px 普通线、2px 主要标题线；主按钮反白，其余操作保持平面。留白承担层次，不把每项信息塞进独立卡片。避免大圆角、玻璃毛玻璃堆叠、彩虹霓虹、通用蓝紫渐变和满屏粒子。

参考桌面值：侧栏 216px，顶栏 73px，观测列 354px，列间距 30px；这些是示例，不是跨项目布局硬约束。数据表、对话、图编辑器、实验工作台各用适合业务的布局。

## 认知任务

保持一个清楚的主要工作面和下一操作。非必要记录按需展开；草稿保留，正式提交不突然清空阅读内容。后台任务不抢焦点、不自动滚动正在阅读的区域。恢复位置应由真实保存状态决定。

环境动态可暂停；书写暂停可由用户选择。环境与交互动效独立控制。不要通过无限慢、透明到不可见来消除动效：使用者已经明确要求可观赏、可辨认的效果。

## 项目变化边界

允许改变：产品名、对象与任务、菜单、内容密度、列数、控件组合、业务状态、必要的状态色。

保持一致：主题 token、字体角色、线框和留白语法、按钮层级、动效机制、清晰度与暂停控制。

没有实际任务 ID／状态／权限时不要编造。研究对象可以是代码、记忆、证明或材料，不必都叫“实验”。
