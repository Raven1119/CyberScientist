# 动效规则

用户选择过十五个来源，并要求保留原效果的辨识度。V9 是当前动效基准。该基准是原始 shader + 应用级 DOM/WebGL 适配，不能声称所有内容都是未改动的 React 原组件。

## 两个层级

**常态**：在限定观测区域内，一次清楚展示一种效果。可暂停、调速、放大；不要把多种效果以极低透明度叠成一层看不清的噪声。输入区、正文、导航位置稳定。

**交互**：在有效对象和状态变更处触发；保留源动效的空间结构与节奏。不要到处附加弹簧、触须、抖动或扫光。

## 十五项的用途

| ID | 效果 | 应用位置与约束 |
|---|---|---|
| PS-06 | Dithering | 观测窗；有形状的双色抖色，不是全屏噪点 |
| PS-10 | Metaballs | 观测窗；清晰团块相遇、融合 |
| RB-01 | Threads | 观测窗；线束形态及指针偏转 |
| RB-08 | Dot Grid | 观测窗／实际图形控制区；邻域响应、点击冲击 |
| RB-16 | Particles | 观测窗；可见深度，不穿越正文 |
| RB-29 | Target Cursor | 指针进入可操作控件时出现角标；保留系统指针 |
| RB-34 | Pixel Transition | 局部观测模式切换、档案翻面 |
| RB-35 | Animated Content | 新视图／对话框进场；不重复重播当前正文 |
| RB-44 | Meta Balls | 观测窗；指针融合与自主运动 |
| RB-45 | Decrypted Text | 短编号／状态；不应用于长段中文 |
| RB-46 | Scrambled Text | 样本室或明确互动的小段技术文字；不扰动工作正文 |
| RB-48 | Split Text | 新标题出现；不在每次输入时重播 |
| RB-53 | Text Type | 新到消息；历史内容不重打，不循环删除 |
| RB-59 | Elastic Slider | 真正有数值意义的调速器；保留键盘操作 |
| RB-60 | Stepper | 实际分步表单；不能伪造任务进度或强迫所有研究分阶段 |

每个项目按任务选用，不要求每页同时用完。完整来源与代码锚点在 `assets/motion-map.json`。

## 像素切换：不可改错

参考方法 `Motion.pixelTransition(host, swap, {gridSize:12, animationStepDuration:.3})`。

先用不透明方块逐步填满局部容器，约 300ms；在完全遮挡时替换；再用另一随机顺序退去，约 300ms。遮罩不承担业务决策。快速重复操作需要取消旧任务并提交最新状态；动效关闭时直接完成替换。

**不接受**：半透明方块全屏闪烁、一道移动扫描线、乱序改字冒充像素转场、先露出新内容再遮挡旧内容。具体方块形状取决于容器比例，V9 使用等分行列，移植时不要擅自重新采样成另一种算法。

## 默认时序（实际值以代码为准）

目标角标捕获 200ms／收回 300ms；内容进场 600ms；分字 650ms、间隔 30ms；解码步进 40ms；打字步进 25ms；弹性滑杆回位 440ms。观测速率范围 0.15–1.5，默认 0.8。不是所有动效必须用同一条 easing。

## 生命周期

WebGL 区域离屏、页面隐藏、暂停或按设置正在书写时停止绘制；卸载时调用场景的 `dispose()`。切换观测模式后旧 canvas／RAF 必须释放，不能每切一次多一个场景。

尊重 `prefers-reduced-motion` 与显式关闭；关闭后文字立即可读、状态立即到位。主题切换不要重新播放正文。触屏不强制光标悬停；所有主操作有点击／键盘途径。

## 动态验收

看至少两个不同时刻的实录，确认团块／线束／粒子清楚可见且确实变化。暂停时画面停止；编辑光标不跳；缩放／宽度变化后画面无拉伸错误。像素切换需观察遮满与退去两个阶段，不能只检查最后一张截图。
