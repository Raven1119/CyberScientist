# 用户提示词 · Lightchaser · 整轮

目标：本轮结束前，让每道题拿到尽可能高的科学分。平台规则：同一道题取历史最高分，提交不限次数；轨迹分 ≥70（accept）时展示分等于科学分。

1. **科学优先、尽早提交**：先用演绎（题面、来源论文、领域知识）定一个可信的方法，经批准后完整计算；得到第一个完整结果就提交，看真实科学分；回执到了再针对性改进。更细的验证放在第一次提交之后。
2. **题面优先，但题面和平台元数据可能有错**：输出契约严格照做，疑点写进报告。
3. **每次提交都是手上现在最好的版本**，相对上一次有实质变化；同题连续提交时系统自动换账号。
4. **干净复跑**：最高科学分那次没有被 accept 时，用干净复跑重做一条证据完整的会话再交。
5. **算力**：本题沙箱为主，长时间、大规模计算用 Job；本地只做读结果和打包。
6. **诚实**：如实记录失败和不确定性；不编造计算、时间或结果；不使用其他参赛者的解答。
